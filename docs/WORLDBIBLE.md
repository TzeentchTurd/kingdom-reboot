# World Bible（V4.0 黑色幽默实验手册）

这不是论文。这是观众席卖爆米花、角色帐上起泡沫、系统拿着剪刀的剧场记录。

## 版本语义（传承但更直白）
- V2.5：设定过多，乐子太少。把“真相”先装箱。
- V3.0：玩法优先。掀箱，拿走能玩的，其余沉底。
- V4.0：给玩家递刀。机制长在笑话里，笑点会流血。
- V5.0：所见即机制。UI 是契约，规则不开玩笑。
- V‑Final：让系统说最后一句。角色欠的账、付的血，都算数。

---

## 派系一：Goblins（理性商人 + 债务泡沫）

无聊版（删）：贪财、爱交易、小聪明。

我们的 V4.0：他们是计算器。用债换时间，用时间吹泡沫，再把泡沫打包卖回给你。

黑色幽默/叙事诡计钩子（可实现）
- 负债货币（Debt Scrip）：以“欠条”结算，折价购买战场增益；回合末按利率叠加“泡沫层”。泡沫破裂时全队 `hp_ratio` 按层数扣减。
- 套保商贩（Hedge Vendor）：EventBoard 随机商人，提供“对冲合同”道具，签署后对下一场战斗某类伤害获得返利，但若未命中则收取违约金（扣 Essence）。
- 带息召唤（Leveraged Spawn）：临时借兵，进入场时附加 `debt_ticks`；若在计时内取胜则清债，否则单位战后被 `removed`。
- 平仓爆音（Margin Call SFX）：当总债超阈值，播放清脆收银机声并强制弃置最高价装备一件（UI 弹窗带价格明细）。

## 派系二：Elves（高贵的奴隶 + 科技伪装魔法）

无聊版（删）：优雅、长寿、会魔法。

我们的 V4.0：他们的“魔法”有保修卡。项圈是真，法杖是假，发光只是散热不良。

黑色幽默/叙事诡计钩子（可实现）
- 冠冕即项圈（Collar Protocol）：精灵单位生成时可带“冠冕”外观插件；被控制时冠冕短暂显露为项圈，触发 `stability_loss` 与短时沉默。
- 机核幻术（Firmware Glamour）：部分“法术”是设备特效；在低电量时强度衰减并溢出电弧（对友军造成1次微伤害并暴露隐形单位）。
- 主人指令（Master’s Command）：战斗开局可绑定1名“主人”；当主人倒地，精灵全体获得“违令惩戒”DOT，除非支付 Essence 解除合同。
- 售后召回（Recall Notice）：Resolution 可触发召回事件，清除一个高危“法术固件”，代价是失去该技能的升级分支。

## 派系三：Witches（傲慢的虐待者 + 实验品B）

无聊版（删）：神秘、残忍、玩毒。

我们的 V4.0：她们把怜悯做成样机，把你做成 B 版。每次试验，都在找更痛的答案。

黑色幽默/叙事诡计钩子（可实现）
- 实验品B（Specimen B）：场上首次倒地的友方被打上 `specimen_b` 标签；被救回时触发“升级惩罚”——随机插入一个副作用词条（如冷却延长/受治疗减半）。
- 仪式超频（Overclock Rite）：施法可切入“超频”以换取即时强力；超频结束按施法时间对施法者扣除等额 Essence（UI 用烧屏特效）。
- 互斩协议（Mutual Protocol）：当女巫开始对敌人提取（`extraction_start`）时，可激活“互斩”——若对方生命反弹至阈值，则双方同时进入流血并判定 `v_kill`。
- 标本橱窗（Specimen Showcase）：EventBoard 事件，可将本局一个倒地敌人的词条“钉”到面板，换取一次临时同名词条（带腐化副作用）。

## 派系四：The Fallen（傲慢的征服者 + 放大的征服欲）

无聊版（删）：好战、扩张、旧王朝。

我们的 V4.0：他们征服一切，包括微不足道。清单里有大陆、海峡、你的水杯，还有——牙刷。

黑色幽默/叙事诡计钩子（可实现）
- 战利计量（Trophy Meter）：每移除一个敌方单位，叠加“战利”层；层数越高，敌方士气越低，但 Fallen 自身受“狂热走火”几率上升（误伤友军）。
- 牙刷诏令（Toothbrush Decree）：随机生成荒诞支线“寻找皇帝的牙刷”；完成则全队获得“洁癖光环”（对脏污地块免疫减益），失败则城内传谣导致 EventBoard 价格上浮。
- 陨落旗语（Fallen Banner）：部署时可插旗；旗在，范围内友军获得推进；旗亡，则触发“羞辱回响”，全队短时 `stun` 0.5s。
- 占领即税（Occupation Tax）：回合开始占有更多格子时，系统自动征收敌方少量 Essence；若超阈被视作“暴征”，生成叛乱小队。

## 实装提示（供设计与工程）
- 所有派系钩子均可映射为状态、词条或事件：如 `debt_ticks`、`stability_loss`、`specimen_b`、`trophy_meter` 等。
- 与 Flow Spec 对齐：战间插曲使用 EventBoard 触发上述派系事件；战斗内逻辑在 BattleBoard 以词条/计量落地；结算影响在 Resolution 结转。
- UI 用明确数值与特效反馈，拒绝“暗箱”：泡沫层数、项圈显露、超频灼烧、旗语范围，都要可见可数。
